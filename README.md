# Чек-лист тестирования веб-формы «Создание / Редактирование площадки»

Данный проект представляет собой пример тестовой документации, разработанной для проверки функциональности, валидации полей и граничных значений формы создания/редактирования площадки.

---

## Технологии и инструменты
* **Тип документации:** Чек-лист (Checklist)
* **Методы тест-дизайна:** Эквивалентное разделение, анализ граничных значений, негативное тестирование, проверка безопасности (XSS / скрипты).
* **Формат оформления:** Markdown

---

## Чек-лист проверок

### 1. Общие проверки формы
-  Открытие формы: все поля пустые, кнопка «Продолжить» неактивна
-  Отображение Placeholder во всех полях
-  Закрытие формы при нажатии на «Крестик»
-  Закрытие формы при нажатии кнопки «Отменить»
-  Активация кнопки «Продолжить» только при всех корректно заполненных обязательных полях
-  Попытка отправки формы с незаполненными обязательными полями (проверка сообщений об ошибках)

### 2. Поле «Название площадки»
-  Оставление поля пустым
-  Ввод валидного названия
-  Исчезновение Placeholder при начале ввода
-  Ввод названия со спецсимволами
-  Ввод названия с пробелами / состоящего только из пробелов
-  Ввод максимального допустимого количества символов
-  Граничные значения: ввод на 1 символ больше максимального лимита
-  Проверка защиты: ввод скриптов (`<script>alert(1)</script>`)

### 3. Выбор цвета («Цвет выделения площадки»)
-  Клик на TextBox: открытие панели выбора цвета
-  Выбор цвета кликом по палитре / градиенту
-  Выбор цвета из пресетов под градиентом
-  Ручной ввод HEX-кода с символом `#` (например, `#FF5733`)
-  Ручной ввод HEX-кода без символа `#`
-  Ввод HEX-кода в нижнем регистре (например, `#ff5733`)
-  Ввод невалидного HEX-кода (несуществующий код / неверный формат)
-  Ввод значения превышающего длину HEX-кода
-  Сброс выбранного цвета с помощью кнопки `x`
-  Отображение подсказки при клике на `?`

### 4. Поле «Описание»
-  Ввод валидного текста
-  Ввод текста со спецсимволами
-  Исчезновение Placeholder при начале ввода
-  Ввод максимального количества символов и проверка границы (+1 символ)
-  Оставление поля пустым (проверка обязательности)
-  Ввод только пробелов
-  Проверка переноса строки (курсор переходит на новую строку)
-  Проверка защиты: ввод HTML/JS-скриптов

### 5. Поле «Габариты площадки»
-  Ввод валидных значений в каждый TextBox («Длина», «Ширина», «Высота»)
-  Ввод отрицательных и дробных чисел
-  Ввод значения `0`
-  Ввод спецсимволов и буквенных значений
-  Проверка защиты: ввод скриптов
-  Ввод максимальных значений и проверка границ (+1)
-  Автоматический перерасчет поля «Площадь» при изменении Длины/Ширины
-  Автоматический расчет вместимости
-  Отображение подсказки при клике на `?`

### 6. Загрузка файла «Схема площадки RDF»
-  Загрузка валидного файла в формате `.pdf`
-  Загрузка невалидного формата (например, `.png`, `.exe`, `.docx`)
-  Загрузка файла максимально допустимого размера
-  Загрузка файла, превышающего максимальный размер
-  Загрузка файла размером `0.00 МБ`
-  Отображение названия и иконки загруженного файла на макете
-  Возможность изменения или удаления уже загруженного файла
-  Загрузка поврежденного / битого файла
